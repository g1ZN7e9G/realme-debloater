Debloat your Realme / ColorOS / OxygenOS phone from the browser

Connects over WebUSB (no ADB install), scans every package on the device and shows what each one is, where it came from, how big it is and whether it is safe to touch.

  1. Enable USB debugging in Developer options and plug the phone in.
  2. On Windows, close any running ADB server first: adb kill-server. Only one program can own the USB interface.
  3. Use Chrome or Edge, click Connect device, pick the phone, then tap Allow on the phone's debugging prompt.
